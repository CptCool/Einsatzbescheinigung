Einstellungen

E-Mail
Optional. Mehrere Adressen mit Komma trennen.

Im Browser entstehen die Entwürfe als .eml-Dateien mit PDF-Anhang: Outlook (klassisch) und Thunderbird öffnen sie per Doppelklick als bearbeitbaren Entwurf. Alternativ öffnet „Im Mailprogramm öffnen“ eine neue Mail mit Empfänger, Betreff und Text – das PDF dann bitte selbst anhängen. Gesendet wird immer nur von Ihnen selbst.

Ablage

Die PDFs bleiben im Browser gespeichert, damit sich vergessene Kameraden später ergänzen lassen. Unter „Gespeicherte Einsätze“ lassen sie sich jederzeit wieder herunterladen.

Daten in diesem Browser

Kontakte, Vorlage, Einstellungen und Bescheinigungen werden nur in diesem Browser auf diesem Rechner gespeichert – nichts davon wird an einen Server übertragen.

Werden die Browserdaten gelöscht (z. B. „Browserdaten löschen“ oder eine Firmenrichtlinie beim Schließen des Browsers), sind auch diese Daten weg. Deshalb regelmäßig eine Datensicherung herunterladen – mit ihr lässt sich auch auf einen anderen Rechner umziehen.
